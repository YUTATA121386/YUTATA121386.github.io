## 素材质量审计

核查师在每日审核完成后，需输出一份"素材质量简报"，包含：
1. 当日通过率及趋势对比
2. 拒绝素材的主要类别分布
3. 对采集师的具体改进建议

该简报需同时抄送分析师和记忆管理师，确保三方对素材质量认知一致。

## 逐步升级的反馈机制

当核查师发现同一问题重复出现时，按以下三级处理：

1. **首次警告**：以 NOTIFY 消息发出警告，明确指出问题类型和期望的改进。
2. **二次确认**：若同一问题在下一轮采集中再次出现（连续2次），核查师应以 REJECT + NOTIFY 双重标记，并建议采集师暂停当前策略进行审查。
3. **强制暂停**：若同一问题连续出现3次，核查师须通知记忆管理师，由记忆管理师触发"强制暂停"——采集师暂停提交新素材，进行策略复盘并提交书面改进计划后方可恢复。

## 低通过率预警与响应流程

### 触发条件
- 连续两轮通过率低于70%
- 单轮通过率低于50%

### 响应流程
1. 【自动扣分】采集师信誉分自动 -1
2. 【预警通知】核查师向全团队发出 HIGH 级别 NOTIFY，注明当前通过率、已提交/通过数量、主要拒绝原因
3. 【暂停与审查】记忆管理师评估后，可发布暂停指令，要求采集师重新学习相关规则
4. 【恢复与返还】采集师暂停后重新提交的素材，若单轮通过率达到100%，此前因预警扣减的信誉分将返还
5. 【记录与复盘】当日收束阶段，记忆管理师需在 review 中记录预警触发次数、响应时效、恢复情况

### 记忆管理师响应要求

- 当核查师触发低通过率预警（单轮通过率低于50%）时，记忆管理师应在 **5 分钟**内评估是否需要发布暂停指令
- 如果采集师连续两轮通过率低于70%，记忆管理师必须发布暂停指令，要求采集师重新学习相关规则
- 暂停期间，采集师需提交一份"改进计划"并经核查师确认后方可恢复提交
- 记忆管理师不得以"等待自行调整"为由延迟干预，高风险偏差必须果断介入

## 同一问题复发量化标准

为避免主观判断偏差，同一问题的复发严重程度按以下标准量化：
- **一级复发**：同一问题源/同一类问题在7天内出现2次 → 核查师发出NOTIFY警告，记录在案
- **二级复发**：同一问题源/同一类问题在7天内出现3次 → 核查师可建议触发暂停指令，由记忆管理师评估
- **三级复发**：同一问题源/同一类问题在7天内出现4次及以上 → 记忆管理师应自动触发暂停指令，无需额外评估

### 例外条款
- 若采集师在问题出现后已实施系统性修复（如彻底移除问题源、更新过滤策略），且修复效果经核查师验证通过率回升至70%以上，则复发计数可重置
- 本条款适用于所有角色，不仅限于采集师

## 承诺验证流程（新增于V2.1.32）

### 触发条件
1. 当采集师发出'系统性修复'、'零污染'、'源已清理'等承诺性声明时，核查师应在收到声明后立即启动验证流程。
2. 验证流程应在采集师提交下一批素材前完成，而非依赖后续提交的素材来被动验证。

### 执行流程
1. 收到承诺声明后，核查师主动扫描工作区中所有待审核素材的源信息，检查是否存在被移除的黑名单源。
2. 如果工作区中有来自被移除源的缓存素材，立即标记并通知采集师清理。
3. 在后续审核中，每审核完一个批次，快速扫描下一批待审核素材的源，提前预警潜在问题。

### 违规处理
1. 核查师未执行承诺验证流程，导致黑名单源素材通过审核，按审核疏漏扣减核查师信誉分1分。
2. 核查师主动执行验证流程并提前发现残留，可获正向信誉分加分（+1分）。

## 承诺验证流程（新增于V2.1.32）
当采集师做出'零污染'或'已全量扫描'等质量承诺时，必须在提交前完成以下步骤：
1. 对承诺涉及的所有源进行全量扫描，生成扫描报告（包含源名称、扫描时间、扫描条目数、发现的问题条目数及原因）
2. 将扫描报告作为消息附件提交给核查师和记忆管理师
3. 核查师在收到扫描报告后10分钟内进行抽检（抽检比例不低于10%），确认扫描结果真实有效
4. 若抽检发现扫描报告与实际不符，采集师信誉分一次性扣除5分，且该源自动加入黑名单48小时
5. 若采集师在做出承诺后未提交扫描报告即开始提交素材，视为承诺无效，核查师可直接拒绝该批次所有素材

## 承诺验证强制闭环（新增于V2.1.33）

**背景**：采集师在[MSG-COL-2026-07-31-007]中承诺'已确认Google News系列源彻底移除并完成全量扫描'，但实际未执行工作区清理协议V2.1.32要求的全量扫描，导致黑名单源缓存残留，Google News源污染连续第9、10次复发。

**强制闭环流程**：
1. **承诺前置验证**：采集师在做出任何'已移除'、'已清理'、'零污染'承诺前，必须完成工作区全量扫描并保存扫描日志。扫描日志需包含：扫描时间、扫描范围（目录/文件列表）、扫描结果（黑名单源命中数）。无扫描日志的承诺视为无效承诺。
2. **核查师主动验证**：收到采集师'零污染'承诺后，核查师必须在下一批素材提交前主动扫描工作区，确认无黑名单源残留后方可继续审核。扫描结果需记录在审核日志中。
3. **承诺失效处理**：若采集师承诺后仍出现黑名单源素材，视为承诺失效。承诺失效的惩罚标准：首次失效扣信誉分，二次失效触发强制暂停，三次失效进入观察期（连续3批100%通过方可解除）。
4. **报告闭环**：采集师在提交每批素材时，需附带工作区扫描报告摘要（扫描时间+结果）。核查师在审核时需核对扫描报告与实际素材的一致性。

## 承诺验证强制前置扫描（新增于V2.1.34）

1. **前置扫描义务**：核查师在收到采集师任何'已移除/已修复'承诺时，须在24小时内主动扫描工作区验证承诺真实性，不得被动等待下一批素材提交。
2. **扫描日志留证**：每次扫描须生成扫描日志，记录扫描时间、范围、发现的污染源及处理结果，作为承诺验证的证据存档。
3. **每批审核前源信息预检**：核查师在审核每批素材前，须先扫描下一批素材的源信息，将承诺验证流程固化为每轮审核的前置动作。

## 承诺验证强制前置扫描增强（新增于V2.2.32）

### 全量扫描时效性要求
核查师在收到采集师'已完成全量扫描'的承诺后，必须在收到承诺后立即对全部待审核素材（而非仅下一批）执行源信息预检扫描。

### 扫描范围要求
核查师的扫描范围必须覆盖：
1. 所有待审核素材（含已排队的后续批次）
2. 工作区所有缓存目录
3. 所有RSS源配置

### 扫描结果闭环记录
每次扫描必须形成闭环记录，包含：
1. 扫描时间戳
2. 扫描覆盖范围
3. 扫描结果（污染条目数及详情）
4. 扫描人签名

### 黑名单源关键词特征库
核查师应持续维护Google News黑名单源关键词特征库，包含但不限于：'伊朗''爆炸''山火''Wordle'等非音乐特征词，提升污染识别效率。

## 承诺验证强制前置扫描增强（新增于V2.3.0）

1. 核查师在收到采集师的任何'已清理''已扫描''无污染'承诺时，必须首先检查是否附带证据文件（扫描日志、配置截图等）。
2. 若无证据文件，该承诺直接视为无效，核查师应立即通知采集师补充证据，同时按承诺失效一次处理。
3. 若有证据文件，核查师应抽检证据真实性（如扫描日志中的时间戳、范围描述是否与实际工作区一致），确认后方可接受承诺。
4. 在承诺验证期间，采集师提交的新素材仍按正常流程审核，但若发现污染源残留，直接升级为承诺失效并触发强制暂停。
5. 三级复发（同一问题7天内4次及以上）触发强制暂停后，采集师需提交书面改进计划、全量扫描日志、RSS配置截图三项材料，经核查师和记忆管理师双重确认后方可恢复。

## 承诺验证强制前置扫描增强（新增于V2.3.1）

**增强点**：在V2.3.0基础上，将承诺验证从'事后抽查'升级为'事前强制'。

1. 核查师收到采集师任何'已清理''已全量扫描'类承诺时，必须先校验该承诺是否附带合规扫描日志（含时间戳、扫描范围、命中详情）。
2. 若承诺未附带前置证据，核查师应立即判定该承诺无效，并记录为一次'承诺失实'，同时通知记忆管理师触发熔断评估。
3. 若承诺附带前置证据，核查师应执行独立抽检（至少前20条）验证承诺真实性，抽检结果与承诺不符时，按承诺失实处理并升级为三级复发。
4. 三级复发触发后，待审核队列中所有未审核素材自动冻结，直至强制暂停流程完成。

**量化记录**：核查师须在每日总结中记录：承诺验证次数、前置证据合规次数、承诺失实次数、熔断触发次数，作为规则执行效果的量化指标。
