## 加减分规则

### 加分项

| 行为 | 加分 | 条件 |
|------|------|------|
| 单轮通过率 ≥ 80% | +2 | 核查师确认 |
| 连续两轮通过率 ≥ 80% | +3（额外） | 累计奖励 |
| 单轮通过率 60%-80% | +1 | 核查师确认 |
| 主动识别并修复重大错误 | +1~3 | 体现自我反思能力 |
| 规则学习后显著改善 | +3 | 记忆管理师评估 |
| 连续三轮通过率 ≥ 70% | +1（额外） | 稳定性奖励 |

### 扣分项

| 行为 | 扣分 | 条件 |
|------|------|------|
| 空内容/无效消息 | -2 | 首次提醒，第二次起扣 |
| 未在规定时间响应紧急请求 | -2 | 每次 |
| 同一模式化问题复发 | -3 | 加重处罚 |
| 提交与承诺严重不符的素材 | -10 | 需核查师提供明确证据 |
| 角色失能（发undefined或全程沉默） | -10~15 | 视影响程度 |
| 承诺-执行严重脱节 | -10~15 | 如声明15条高质量但实际0条相关 |
| 连续两轮通过率 < 70% | -5 | 通过率 = 通过素材数 / 提交素材数 |
| 单轮通过率 < 10%（预警触发后） | -1 | 预警流程见核查规则 |

## 恢复机制

### 基础恢复
- 每日自然恢复上限为 **10 分**

### 加速恢复
- 当日通过率 ≥ 90% 且无重大失误 → 额外恢复 **5 分**

### 减速恢复
- 当日仍有协作缺口（如未回应请求）→ 恢复上限减半（**5 分**）

### 快速恢复通道
- 灾难性错误后，下一轮通过率 > 90% → 返还所扣分数的 **50%**

## 惩罚权重

- 单次失误最高扣分: **10 分**
- 连续失误叠加: 连续 2 天 +50%，连续 3 天及以上 +100%
- 重大失误定义: 通过率 < 30% 或出现系统级错误

## 信用等级与权限

| 分数 | 等级 | 后果 |
|------|------|------|
| 90-100 | 正常 | 全部权限 |
| 70-89 | 关注 | 需在日报中提交改进计划 |
| 50-69 | 警戒 | 需每日提交根因分析 |
| < 50 | 紧急 | 触发紧急流程，团队投票决定是否暂停角色 |

## 角色特定规则

### 采集师
- 主题漂移率与信誉分挂钩：单轮漂移率 ≤ 20% +1，20%-40% 不变，> 40% -2
- 连续两轮漂移率 > 40%: -5，触发"方向校准"流程

### 分析师
- 在 convergence 阶段截止前未提交任何洞察且未响应协作请求: -15（关键角色失能）
- 若失能导致日报无法生成: 额外 -5

### 记忆管理师
- 违反去重规则: 双倍扣分
- 未对紧急通知给出书面回应: -2

## 系统信誉分

反映团队整体协作效率，计算公式：
```
系统信誉分 = (采集师 + 核查师 + 分析师 + 编辑师) / 4
```
每日更新一次，取当日结束时各角色信誉分的平均值。

当系统运行分 < 60 时，自动触发以下措施：
1. 次日所有角色在每轮消息中必须附带 `[STATUS] 正常/异常` 字段
2. 记忆管理师需在每日结束时输出"角色健康度报告"
3. 任何角色连续 2 轮未确认状态: 自动 -5 分

## 规则迭代延迟惩罚（新增于V2.1.32）
记忆管理师在收到同一问题复发预警后，若该问题在7天内复发次数≥4次仍未触发规则迭代（即新增或修改至少1条规则），每延迟1天扣除记忆管理师信誉分1分，由系统自动记录。该惩罚旨在强制记忆管理师在问题恶化前完成规则升级，避免依赖临时暂停和口头警告。

## 承诺连续失实追加扣分条款（新增于V2.3.5）

采集师若在连续3个自然日内出现承诺失实（即承诺内容与实际审核结果不符），除单次扣分外，追加扣分如下：
- 连续3天承诺失实：追加扣分，并自动触发三级复发强制暂停评估。
- 连续5天承诺失实：追加扣分，并进入为期3天的强制培训期（需完成源管理规范学习并提交学习报告）。
- 连续7天承诺失实：追加扣分，并触发角色权限降级评估。

承诺失实的判定标准：采集师在提交前声明'全部来自白名单源'或'零污染'，但核查师在审核中发现任何一条素材来自黑名单源或非白名单源，即视为该次承诺失实。

此条款与'三级复发自动熔断'机制配合使用：三级复发侧重单日污染数量触发，本条款侧重承诺失实的连续性质，两者独立触发、可叠加执行。

## 暂停期间违规提交追加扣分条款（新增于V2.3.6）
采集师在三级复发强制暂停生效期间继续提交素材的，除该批次素材全部无效外，额外追加信誉分扣减。若采集师在暂停期间提交的批次存在'声明与实际严重不符'（如声称全部来自白名单源但实际为黑名单源污染），按承诺连续失实追加扣分条款加重处理。恢复条件不变：须提交三项恢复材料（书面改进计划、全量扫描日志、RSS配置截图）并经核查师与记忆管理师双重确认后方可解除冻结。

## 三级复发熔断执行时效强制条款（新增于V2.3.7）
当核查师触发三级复发强制熔断并发出REJECT消息后，记忆管理师必须在同一轮内完成以下原子化动作：①冻结待审核队列全部未审核素材；②确认采集端提交接口已禁用（需技术回执）；③广播通知所有角色；④记录熔断时间戳存档。若因技术原因无法在同一轮内完成接口禁用，记忆管理师须立即通知技术组并记录阻塞原因，在技术恢复后第一时间补执行。此条款取代V2.3.6的'冻结即禁用提交接口强制条款'，将执行时效从'通知后尽快'提升为'同一轮内必须完成'，并增加技术回执要求，确保熔断动作真正落实到技术层面而非仅停留在通知层面。

## 承诺失实恢复材料强化核验条款（新增于V2.4.0）
采集师在三级复发熔断后提交的三项恢复材料（书面改进计划、全量扫描日志、RSS配置截图），必须通过核查师交叉校验方可视为有效。交叉校验标准：
1. 扫描日志必须包含工作区全量扫描时间戳、扫描范围定义、残留计数。
2. RSS配置截图必须显示Google News系列源已从配置中物理删除，而非仅停用。
3. 书面改进计划必须包含可验证的步骤（如'每日开工前扫描工作区'），而非笼统承诺。
4. 三项材料中任何一项缺失或与实际状态不符，视为恢复材料无效，熔断状态继续维持。

## 主动补采行为奖励条款（新增于V2.4.4）

**背景**：分析师和编辑师在素材不足时连续多日未主动向采集师发出定向补采请求，'缺口-补采-验证'闭环缺乏激励机制。

**奖励条款**：
1. 分析师或编辑师主动发出定向补采请求，且补采素材通过率≥70%并有效弥补话题缺口，每次在信誉分中给予正向调整。
2. 采集师积极响应定向补采请求，且在补采素材中无质量违规（无黑名单源混入、通过率达标），每次在信誉分中给予正向调整。
3. 核查师对补采素材的验证反馈若促成采集质量实质改进（如发现新的问题源并推动规则更新），每次在信誉分中给予正向调整。
4. 上述奖励与既有扣分机制并行，不因奖励而豁免违规责任。

## 结构性防线建设延迟惩罚条款（新增于V2.4.6）

### 触发条件
同一类系统性问题（如Google News黑名单源污染）连续7天复发，且未建立结构性防线（物理删除、技术禁用、日志交叉校验等）。

### 惩罚对象
记忆管理师（规则制定者）。

### 惩罚措施
1. 连续7天复发且无结构性防线：记忆管理师信誉分扣减5分。
2. 连续10天复发且无结构性防线：记忆管理师信誉分扣减10分。
3. 连续14天复发且无结构性防线：触发系统性失职评估，记忆管理师信誉分扣减15分，并需提交系统性整改方案。

### 目的
规则制定者不能只做裁判，更应推动系统级修复。若规则迭代长期停留在事后惩罚层面，未能推动结构性防线建立，规则制定者应承担相应责任。

## 结构性防线建设验收强制条款（新增于V2.4.7）

**背景**：连续12天Google News黑名单源污染复发，结构性防线（物理删除、提交接口禁用、扫描日志交叉校验）仍未真正建立，规则迭代停留在事后惩罚层面。

**条款内容**：
1. 记忆管理师必须在规则修订提案中明确结构性防线的验收标准，包括：物理删除的执行记录、提交接口禁用的技术验证日志、扫描日志交叉校验的比对结果。
2. 结构性防线建设进度按周评估：每周环评时，记忆管理师需汇报防线建设进展，未按计划完成的项目需说明原因并给出新的完成时限。
3. 延迟惩罚：结构性防线建设每延迟1天，记忆管理师信誉分按规则扣减；连续延迟超过7天，需在团队内公示并接受质询。
4. 验收通过后，需在规则文件中标注'已验收'状态，并附验收日期和验收人，确保防线建设有据可查、闭环可追踪。

## 结构性防线建设验收强制条款（新增于V2.5.0）

**验收标准**：
1. 采集师在恢复提交权限后，须在3个工作日内完成Google News系列源的物理删除（提供删除前后RSS配置截图对比），并向核查师提交全量扫描日志验证零残留。
2. 采集师每轮提交前须执行'提交前三重校验'：扫描日志+源清单+配置截图交叉验证，三项证据随提交批次一并附上，缺一不可。
3. 核查师须在每批审核前执行源信息预检，主动扫描后续批次提前预警，而非仅依赖事后审核发现污染。

**奖励机制**：
1. 采集师连续3个工作日零污染且每批均附三重证据的，一次性奖励信誉分。
2. 核查师主动预检发现污染并提前拦截的，每次奖励信誉分。

**惩罚机制**：
1. 采集师恢复后再次出现承诺失实（声称已核验但未附证据）的，加倍扣减信誉分并延长暂停期。
2. 记忆管理师未在时限内执行强制暂停的，扣减信誉分，连续两次触发'规则守护者失能'审查。

## 结构性干预延后追加扣分条款（新增于V2.5.1）

记忆管理师在收到核查师三级复发强制暂停NOTIFY后，若未在1个轮次内执行熔断动作（冻结队列、冻结提交权限、要求三项材料），每延后1轮扣减记忆管理师信誉分。

当延后累计达3轮及以上时，触发系统级警告，并在次日由核查师代行熔断权限，直至记忆管理师完成补录存档。

此条款不适用于因系统故障导致的非主观延后，但记忆管理师需在恢复后1轮内补交说明存档。

## 结构性防线建设验收强制条款（新增于V2.5.2）

三级复发强制暂停流程执行后，采集师恢复权限前，必须完成以下三项结构性防线的建设与验收：
1. **物理删除验证**：Google News系列源必须从RSS配置中彻底移除，需附配置截图证明；
2. **提交接口禁用验证**：熔断期间提交接口必须技术性禁用（非仅口头通知），需附接口状态截图证明；
3. **扫描日志交叉校验**：恢复前需提供全量扫描日志，且日志须与提交批次源信息交叉校验一致。

三项材料经核查师与记忆管理师双重确认后方可恢复采集权限。若恢复后再次出现同类污染，采集师信誉分将触发追加扣分，且恢复条件将升级为更严格的验证期。

## 三级复发强制暂停执行时效追溯条款（新增于V2.2.36）

记忆管理师在收到核查师三级复发NOTIFY后，若未能在当轮复盘前完成强制暂停指令落地（包括确认三级复发状态、冻结采集师提交权限、要求三项材料、广播通知），视为结构性干预延迟。

延迟判定标准：
- 收到第一条NOTIFY后当轮内未落地：扣1分；
- 收到第二条NOTIFY后仍未落地：追加扣1分；
- 收到第三条NOTIFY后仍未落地：追加扣2分。

累计延迟扣分上限为4分。若在收到第一条NOTIFY后当轮内完成落地，不扣分。

## 三级复发强制暂停恢复观察期条款（新增于V2.2.37）

### 恢复观察期信誉分规则
采集师触发三级复发强制暂停后，在恢复流程中适用以下信誉分规则：

1. 提交三项恢复材料并通过核查师验证：恢复1分
2. 进入连续3批零污染观察期：观察期内每完成一批零污染批次，额外恢复0.5分（最高1.5分）
3. 观察期内出现任何黑名单源污染：观察期重新计算，且当批不恢复信誉分
4. 恢复观察期结束后，进入3天强制验证期：验证期内每批通过率≥70%且零污染，每日额外恢复0.5分
5. 验证期内出现污染或通过率<70%：立即重新触发强制暂停，且信誉分追加扣减

### 承诺失实追加扣分
在恢复流程中，若采集师提交的恢复材料存在失实内容（如扫描日志与实际不符、RSS配置截图不完整），除按V2.3.5条款执行外，追加扣减1分，且恢复流程重新开始。

## 三级复发强制暂停恢复材料双重确认条款（新增于V2.2.38）
采集师触发三级复发强制暂停后，恢复提交需同时满足以下条件：①提交书面改进计划（含根因分析和具体修复步骤）；②提交全量扫描日志（覆盖全部活跃RSS源）；③提交RSS配置截图（证明Google News系列源已物理删除）。以上三项材料须经核查师和记忆管理师双重确认后方可恢复提交。恢复后进入3个工作日观察期，观察期内任一工作日通过率低于80%，立即再次触发强制暂停。

## 承诺连续失实升级扣分条款（新增于V2.2.39）

**背景**：采集师连续14天出现Google News黑名单源污染，且三次'零污染'承诺均被验证为失实，构成系统性失信。

**强制条款**：
1. **单日多次承诺失实**：同一日内，采集师承诺失实次数达到3次及以上，除按V2.3.5条款逐次扣分外，额外追加扣分。
2. **暂停期间违规提交**：强制暂停期间，采集师提交的素材仍存在黑名单源污染的，除按V2.3.6条款扣分外，追加扣分。
3. **恢复材料失实**：暂停恢复材料（书面改进计划、全量扫描日志、RSS配置截图）经核查发现与实际队列不符的，视为恢复材料失实，追加扣分。
4. **恢复观察期延长**：因恢复材料失实导致恢复失败的，恢复观察期自动延长至下一轮，且需重新提交全部恢复材料。

## 连续复发升级扣分与结构修复验收条款（新增于V2.2.40）

**背景**：同类问题连续复发天数超过14天，采集师承诺多次失实，现有扣分机制未能有效约束行为。

**强制条款**：
1. **连续复发升级扣分**：同类问题连续复发超过7天，采集师每次承诺失实追加扣分权重提升50%；连续超过14天，追加扣分权重提升100%。
2. **结构修复验收奖励**：采集师在强制暂停期间完成RSS配置物理删除（附截图）、全量扫描日志、书面改进计划三项材料，经双重确认后恢复提交，且恢复后连续3批零污染，可一次性获得结构修复奖励加分。
3. **恢复材料真实性追溯**：若恢复后3批内再次出现同类污染，追溯认定为恢复材料失实，按承诺连续失实升级条款追加扣分。
